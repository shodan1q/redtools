# 精美文字海报 / 金句卡片

把一句话变成一张能直接发的高清卡片。设计上的"精美"来自四件事：**讲究的渐变背景**、
**胶片微噪 + 暗角质感**、**分明的字体层次**、**克制的装饰**（引号、强调线、署名，点到为止）。

## 六套精调配色（`--preset`）

| 预设 | 气质 | 适合 |
|---|---|---|
| `极简白` | 干净、留白、红印点缀 | 干货、书摘、极简风 |
| `暮光` | 蓝紫粉渐变、暖金点缀 | 情绪、治愈、晚安语 |
| `墨黑金` | 黑金、杂志感 | 观点、金句、高级感 |
| `莫兰迪` | 低饱和、温柔 | 生活、随笔、文艺 |
| `薄荷` | 清新绿渐变 | 学习、成长、清爽 |
| `深海` | 深蓝青渐变 | 科技、深度、冷静 |

## 三种比例（`--ratio`）

`3:4` 小红书（默认）· `1:1` 方图 / 朋友圈 · `9:16` 故事 / 手机壁纸

## 怎么用

```bash
# 金句卡（带装饰引号 + 署名）
python3 scripts/poster.py --text "把重复的时间\n还给自己" --sub "工具的意义" \
    --preset 暮光 --quote --signature AgentOPC --out card.png

# 方图观点卡
python3 scripts/poster.py --text "越简单\n越高级" --preset 墨黑金 --ratio 1:1

# 竖版壁纸
python3 scripts/poster.py --text "慢慢来\n比较快" --preset 薄荷 --ratio 9:16
```

- **换行**：用 `\n` 手动断句（推荐——自己控制节奏最好看）；字号会自动缩到每行不被拆开
- **`--quote`**：加装饰大引号，做金句卡用
- **`--sub`**：副标题 / 出处；**`--signature`**：右下角署名（免费的品牌位）

## 出图小技巧

- **一句话别太长**：主文案 6–14 字最出效果，长了就自己 `\n` 断成 2–3 行
- **强调感**：`墨黑金` / `深海` 深色卡，白字 + 一句短话，最像杂志封面
- **成套发**：同一句话换 6 个预设各出一张，或一组金句配同一预设，是小红书很吃的"文字卡"选题
- 生成的卡可当小红书封面、内容配图、引用卡、手机壁纸

## 依赖与说明

- 依赖 `numpy`、`Pillow`（`pip install numpy pillow`）；中文字体自动适配系统字体
- 设计思路参考了常见的开源金句海报做法（渐变 + 排版层次 + 装饰），代码为独立实现
