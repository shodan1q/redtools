# 小红书图文写作规范

`原长文.md` 既是文章也是排版指令——渲染器按下面的语法逐行解析。写作时每个语法选择
都直接决定卡片长相。

## 排版语法（渲染器识别的全部规则）

| 写法 | 渲染效果 | 注意 |
|---|---|---|
| 第一行 | 封面主标题 | 12–20 字；`**词**` 会在封面变强调色 |
| 空行 | 分段 | 段与段之间必须空行 |
| `一、xxx` / `1、xxx` | 小标题（数字徽章 + 大字） | ≤24 字才识别；`一、`后面直接跟文字 |
| `【xxx】` / `# xxx` | 小标题（竖条 + 大字，无徽章） | 用于不想编号的小标题 |
| `- xxx` | 圆点要点，连续行合并成一张圆角卡片 | 每条 ≤40 字，2–5 条一组 |
| `1. xxx`（点+空格） | 数字徽章要点 | 与 `1、`（顿号=小标题）严格区分！ |
| `**词**` / `【词】` / `*词*` | 强调色加粗 | 每页 1–3 处，多了会花 |
| `![图注](路径)` | 整行内联插图（含图注） | 必须单独成行，路径相对项目根 |
| 首段第一句 | 自动提取为封面导语 | ≤48 字，写成钩子 |
| 最后一段 | ≤80 字时自动成为结尾金句页 | 刻意写成一句可转发的话 |

**不支持**：表格、代码块、链接、嵌套列表、引用块（`>` 会被当普通段落）。别写。

## 文章骨架（照此排布）

```
标题：12–20 字，可含一个 **高亮词**

钩子段：2–3 句。第一句 ≤48 字（它会上封面）。抛问题/给反差/亮数据。

一、第一个分论点（≤24 字）

观点段 2–4 句。段落宁短勿长，一段一个意思。

- 要点一（≤40 字，关键词 **加粗**）
- 要点二
- 要点三

![一句话图注](content/<本篇目录>/images/chart-01-xxx.png)

二、第二个分论点
……

结尾金句：≤80 字的一段，独立成页，值得被截图。
```

- 每个 `一、二、三` 小节 = 卡片上的一个视觉锚点，全文 3–5 节。
- 图表放进它所属的小节，顺序用「小标题 → 图表 → 释义段」——图表是整页原子块，
  这个顺序最容易分页成漂亮的整页；`![]()` 里写图注（一句话说清图里看什么）。
- 正文总字数 600–1200 字最稳（阅读 2–5 分钟，9–12 张卡）。
- **防孤儿页**：结尾金句会被单独抽走成页，它前面那段若只有一两行，就会孤零零
  占一整页——金句前的最后一个正文段要么写满 3 行以上，要么并进更前面的段落。

## 标题公式（封面即生死）

| 公式 | 例子 |
|---|---|
| 数字盘点 | 普通人用 AI 的 **5 个段位**，你在哪层 |
| 反常识 | AI 不会取代人类？这话可能是**自我安慰** |
| 结果前置 | 坚持晨跑 100 天，我**退掉了健身房** |
| 身份代入 | 给程序员的 **3 条**转型建议 |
| 悬念缺口 | 为什么你存不下钱？答案在**这张图**里 |

标题避免："浅谈/浅析"、纯名词堆砌、超过 20 字、没有具体数字或冲突点。

**封面换行规则**（标题会以约 7 字/行自动均衡换行，标点不落行首）：
12–16 字的标题，用逗号/问号把语义断点锚在第 7 字附近，就不会把词拆到两行。
例："存不下钱的人，都输在这个顺序"（7+7）稳；"AI不会取代人类这话是自我安慰"（无断点）
会在随机位置拆词。写完标题先数一下字，脑内按 7 字/行折行检查。

## 发布文案（写进概述.md，发笔记时直接复制）

```
【发布标题】≤20 字，可与封面标题不同，更口语
【正文】≤1000 字：
  开头 1–2 句钩子（别复读封面）
  ✅/🔥/📌 emoji 开头的核心点 3–5 行
  一句互动引导（"你在第几层？评论区聊聊"）
【标签】5–10 个：2–3 个大流量词 + 3–5 个垂直词 + 1–2 个长尾词
  例：#AI #人工智能 #职场成长 #AI工具 #认知提升 #普通人逆袭
【发布建议】工作日 12:00–14:00 或 19:00–22:00；发布时主动勾选「AI 生成」标识
  （平台对 AI 生成/合成内容有强制标识要求，隐瞒有封号风险）；发布动作由用户
  手动完成，不做任何形式的自动发布
```

## 语感清单（小红书味）

- 说人话：短句、口语、有"你"。"你会发现" > "由此可见"。
- 具体 > 抽象："0.024%" > "极少数"；"退掉健身房" > "改变生活方式"。
- 每节给一个可带走的东西：数据、方法、金句，三选一。
- 克制 emoji：卡片正文里**不用** emoji（渲染字体不含彩色 emoji，会变黑白豆腐块），
  emoji 只出现在发布文案里。
- 敏感规避：绝对化用词（"最/第一/绝对"）、医疗功效断言、贬损竞品，都会限流。
