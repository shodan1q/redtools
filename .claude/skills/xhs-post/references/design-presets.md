# 设计风格预设库

10 套经过搭配验证的「主题 × 字体 × 底纹 × 封面」组合。选风格时**从内容类型出发查下表，
整套照抄参数**，不要随机拼凑单项——精美感来自搭配的一致性，而不是选项的丰富度。

## 快速决策

1. 判断内容类型 → 在下表找到预设，把「meta 片段」合并进 `meta.json`。
   **注意**：脚手架生成的 meta.json 自带预设 1 的 `customColor`——换用其他预设时
   片段里的 `"customColor": null` 必须一并写入（清掉模板残留，否则强调色被污染）。
2. 按预设的「封面图」栏选 `heroImg`（内置图见文末对照表；无合适图就用该预设的无图方案）
3. 有数据图表时，图表主色用预设的强调色（见 charts-guide.md）

## 1 · 知识浅紫（默认）

浅紫纸面 + 青绿强调 + 公式底纹 + 圆体。浅紫底让大段文字不闷，青绿高亮跳而不刺眼，
公式底纹给"有干货"的暗示，圆体消解知识的距离感。已在实产内容中验证。

```json
{ "themeIndex": 11, "customColor": "#2F9488", "patternIndex": 6,
  "titleFontIndex": 5, "bodyFontIndex": 5, "coverLayout": 1 }
```
封面图：photo-13（暗夜笔记本，万金油）/ photo-06 / photo-07；讲 AI 用 photo-15 或 photo-19。

## 2 · 靛夜极客

深夜蓝底白字 + 计算机底纹 + 海报体标题。深色主题自带屏幕感，代码底纹只在深色上若隐若现，
正文用黑体保证暗底可读性。

```json
{ "themeIndex": 15, "customColor": null, "patternIndex": 10,
  "titleFontIndex": 4, "bodyFontIndex": 0, "coverLayout": 1 }
```
封面图：photo-03（代码雨）/ photo-08 / photo-12 / photo-14 / photo-17。

## 3 · 黛蓝方法论

灰蓝底 + 网格底纹像方格笔记本，黑体标题 + 细黑正文是最"顾问报告"的组合。
适合有步骤、有框架的内容。

```json
{ "themeIndex": 3, "customColor": null, "patternIndex": 1,
  "titleFontIndex": 0, "bodyFontIndex": 1, "coverLayout": 0 }
```
封面图（卡片版式必须配图）：photo-11（屏幕走势图）/ photo-04；讲全局观用 photo-09（太空地球）。

## 4 · 奶油治愈

奶油棕底 + 圆点底纹 + 雅宋标题 + 宋体正文。宋体自带"认真生活"的书卷气，
圆点让页面软下来。生活类内容别用内置科技封面图——用全屏无图（深色渐变+白字也耐看），
或让用户提供生活照后改 `coverLayout: 2` 融入版式。

```json
{ "themeIndex": 1, "customColor": null, "patternIndex": 2,
  "titleFontIndex": 3, "bodyFontIndex": 2, "coverLayout": 1, "heroImg": null }
```

## 5 · 莓粉心事

莓粉底 + 斜线底纹 + 手写标题。手写体只用在标题——整篇手写会难读，
细黑正文把情绪稳住。结尾金句页在这套里最出效果。

```json
{ "themeIndex": 4, "customColor": null, "patternIndex": 3,
  "titleFontIndex": 6, "bodyFontIndex": 1, "coverLayout": 1, "heroImg": null }
```
封面：无图全屏（渐变+白色手写标题即氛围）；用户有人物/情绪照片则 `coverLayout: 2`。

## 6 · 墨黑杂志

墨黑底 + 金橙强调（主题自带）+ 竖线底纹 + 宋体标题。黑金是最稳的高级感公式，
宋体白字在深底上就是杂志封面。观点越锋利越适合。

```json
{ "themeIndex": 14, "customColor": null, "patternIndex": 4,
  "titleFontIndex": 2, "bodyFontIndex": 1, "coverLayout": 1 }
```
封面图：photo-05（金色数据隧道，与黑金呼应，首选）/ photo-01。

## 7 · 薄荷课堂

薄荷绿底 + 数学底纹 + 圆体标题。绿色 = 板书/护眼联想，数学纹呼应学习场景但不抢戏。

```json
{ "themeIndex": 8, "customColor": null, "patternIndex": 7,
  "titleFontIndex": 5, "bodyFontIndex": 0, "coverLayout": 0 }
```
封面图：photo-18（黑板公式，首选）。

## 8 · 青瓷轻养

青瓷底 + 圆点底纹 + 全黑体。最克制的一套，靠留白和青瓷色的"透气感"取胜，
健康类内容要的就是干净可信。

```json
{ "themeIndex": 9, "customColor": null, "patternIndex": 2,
  "titleFontIndex": 0, "bodyFontIndex": 0, "coverLayout": 1, "heroImg": null }
```

## 9 · 藕荷文艺

藕荷底 + 横线底纹像稿纸，雅宋标题 + 宋体正文。写书评影评随笔，标题里挑一个词
`**加高亮**`，紫红强调色会替你做点题。

```json
{ "themeIndex": 10, "customColor": null, "patternIndex": 5,
  "titleFontIndex": 3, "bodyFontIndex": 2, "coverLayout": 1, "heroImg": null }
```
封面：无图全屏；书影音有海报/实拍时 `coverLayout: 2` 融入。

## 10 · 鸿蒙热点

鸿蒙橙 + 无底纹 + 海报体标题。热点要快、要糙得有劲，去掉底纹反而干净利落，
海报体自带音量。清单式内容配 `1. 2. 3.` 数字要点最搭。

```json
{ "themeIndex": 0, "customColor": null, "patternIndex": 0,
  "titleFontIndex": 4, "bodyFontIndex": 0, "coverLayout": 1 }
```
封面图：photo-05 / photo-15（有人物有情绪）。

## 通用微调规则

- **比例**：正文 ≤1200 字用默认 3:4（`ratioIndex: 0`）；1200 字以上或图表多，
  换 3:5 长图（`ratioIndex: 1`），别硬塞。
- **张数**：`targetPages ≈ 字数 ÷ 130 + 图表数`，取 6–12 之间；小红书最多 18 张，
  8–12 张完读率最好。它只是**文字**的分页预算——整页图表/要点卡是原子块，
  由它们造成的留白要用结构手段治（见 writing-guide 与主 SKILL 质检节）。
- **署名**：`signature` 用账号名，出现在封面右下和每页页脚，是免费的品牌位，别留空。
- **结尾页**：`closingOn: true` 时正文最后一段（≤80 字）会独立成金句页；
  写作时刻意把最后一段写成一句可截图转发的话。
- **深色主题（14/15）**只配线条类底纹（4/5/10），点阵和公式在深底上会显脏。
- **手写系字体（6/7/8/9）**只当标题用，正文永远用 0/1/2/5 这四个可读字体。
- **customColor** 只在预设指明时用；自己配色时保证强调色与底色对比度足够
  （浅底配深强调色，深底配亮强调色）。
