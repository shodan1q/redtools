# 炫酷前端界面（浅色简约 · 编辑级）

炫酷不等于花哨。这套走 **Anthropic / Claude 的设计语言**：暖米纸感底、近黑衬线大字、
陶土橙只做点睛、大量留白。冲击力来自**动效、排版与生成艺术**，而不是渐变霓虹。

**硬规矩**：不用渐变色、不用 emoji、只用下面这套暖色。

## 配色（Anthropic 官方色）

| 用途 | 色值 |
|---|---|
| 纸感底 | `#FAF9F5` |
| 近黑（所有文字） | `#141413` |
| 陶土橙（仅交互/点睛） | `#D97757` |
| 中性灰（辅助文字） | `#6b6a63` |
| 备用（少量）| 蓝 `#6A9BCC` · 绿 `#788C5D` |

## 三套模板（`templates/`，均在真实浏览器验证）

| 模板 | 技术 | 效果 |
|---|---|---|
| `1-动态编辑标题.html` | 纯 CSS | 衬线大字逐字入场 + 关键词循环轮换 + 细线绘入，编辑感首屏 |
| `2-水墨流线.html` | p5.js | 生成式流场：上千墨线沿噪声场流动，墨黑与陶土交织成风纹，每次都不同 |
| `3-交互点阵.html` | canvas | 点阵网格，鼠标靠近如透镜把墨点点亮成陶土色、放大外推 |

## 怎么用

1. 挑一套，把里面的**文字**换成你的
2. 配色都用 CSS 变量 `--paper / --ink / --clay` 集中管理，改这三个即可
3. 浏览器打开即成品；发小红书用**录屏**（动效更吸睛）或截图

## 关于动效的两个提示

- **水墨流线**是"累积型"：前台打开约十几秒长成一幅完整水墨，越等越密（后台标签会被浏览器降帧，属正常）
- **想要"高级动效"的公式**：暖底 + 近黑衬线 + 单一陶土点睛 + 缓慢/克制的运动 + 大留白。宁静，才显贵。

## 想扩展更多（让 AI 照着做）

同一套克制语言可延伸：**等高线地形起伏**、**逐字打字机标题**、**滚动视差长页**、
**磁吸按钮/光标**、**极简数据卡片墙**、**衬线 + 点阵结合的作品集首页**。
核心：少即是多，一个陶土色点睛胜过满屏渐变。

## 说明

- 依赖现代浏览器；p5.js 走 CDN（打开时需联网），CSS/canvas 模板纯离线可用
- 每个 `.html` 单文件自包含，可当个人主页 / 落地页 / 动态壁纸
- 设计参考 Anthropic 公开的品牌视觉语言（暖色、衬线、克制），代码为独立实现
