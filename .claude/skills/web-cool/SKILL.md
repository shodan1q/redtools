# 炫酷前端界面生成

产出一个**自包含单文件 `.html`**——浏览器双击打开就是满屏动效。three.js / p5.js 从 CDN 加载，
无需搭环境、无需打包。三套模板都已在真实浏览器验证过。

## 三套模板（`templates/`）

| 模板 | 技术 | 效果 |
|---|---|---|
| `1-粒子星系.html` | three.js | 2.2 万粒子螺旋星系、金核蓝边、鼠标视差旋转 |
| `2-霓虹节点网.html` | p5.js | 星丛节点连线（plexus）、鼠标高亮唤醒、科技感 |
| `3-玻璃拟态着陆页.html` | 纯 CSS | 漂浮渐变光球 + 磨砂玻璃卡 + 渐变按钮，现代落地页 |

## 怎么用

1. 挑一套模板，把里面的**文字**换成你的（标题 / 副标题 / 按钮 / 数据）
2. 想换配色，改顶部的渐变色值（每个模板都用了 `linear-gradient` / 粒子色，集中好找）
3. 浏览器打开即成品；要发小红书就用录屏 / 截图（平台不直接渲染 HTML）

## 改配色 / 换主题的关键位置

- **粒子星系**：`cIn`（内核暖色）、`cOut`（外缘冷色）两行，换这两个颜色即换整体色调
- **霓虹节点网**：`stroke(0,245,212,...)` 连线色、`fill(255,60,166,...)` 鼠标高亮色
- **玻璃拟态**：`.o1~.o4` 四个光球的 `background` 颜色 + `.card` 的透明度

## 想要更多效果（让 AI 照着扩展）

同一套骨架可改成：**波浪起伏地形**（three.js plane + 噪声位移）、**旋转线框地球**、
**代码雨 / 矩阵**（canvas）、**音频可视化风格波纹**、**鼠标拖尾粒子**、**霓虹网格隧道**。
要点：深色底 + 高饱和霓虹色 + 发光（`AdditiveBlending` / `filter:drop-shadow` / `box-shadow`）+
缓慢动画，是"炫酷感"的公式。

## 说明

- 依赖：现代浏览器（Chrome/Safari/Edge）；three.js / p5.js 走 CDN，打开时需联网
- 每个 `.html` 都是**单文件自包含**，可直接分享、可当个人主页 / 落地页 / 动态壁纸
- 设计参考了常见的开源创意编程作品（粒子星系、plexus、glassmorphism），代码为独立实现
