# 引用规范

**文内引用 + 文末参考文献表配套出现，全文只用一种格式，别混。**

## 学术诚信（最重要，先读）

- **不编造文献**：AI 不能凭空生成真实的作者 / 年份 / DOI——那是幻觉，查重和导师一眼识破。
  凡具体引用，给的都是**格式示例**，必须用真实读过的文献替换、逐条核实（撤稿的别引）。
- **按证据说话**：论断强弱匹配证据强度，别把"一项小样本研究"写成"已证实"。
- **AI 使用要披露**：按学校 / 期刊规定如实说明。
- **应独立完成的作业自己写**：本 skill 帮结构、逻辑、格式，不替你把该原创的内容做完。

## GB/T 7714-2015（中文学术国标）

**文内**：顺序编码 `……已有研究[1]`；或著者-出版年 `（张三，2023）`。

**文末**（`[序号] 主要责任者. 题名[文献类型标识]. 出版项.`）：

| 类型 | 标识 | 示例（格式，需替换真实文献） |
|---|---|---|
| 期刊 | [J] | `[1] 张三, 李四. 题名[J]. 刊名, 2023, 12(3): 45-67.` |
| 专著 | [M] | `[2] 王五. 书名[M]. 2版. 北京: 某出版社, 2022: 88-90.` |
| 学位论文 | [D] | `[3] 赵六. 题名[D]. 上海: 某大学, 2021.` |
| 会议论文 | [C] | `[4] 作者. 题名[C]// 论文集名. 出版地: 出版社, 年: 页.` |
| 电子/网络 | [EB/OL] | `[5] 机构. 题名[EB/OL]. (发布日期)[引用日期]. 网址.` |

## APA 7th（国际通用）

**文内**：`(Zhang, 2023)` 或 `Zhang (2023) argued...`；两位作者 `(Zhang & Li, 2023)`；
三位及以上 `(Zhang et al., 2023)`。

**文末**（悬挂缩进）：

```
Zhang, S., & Li, M. (2023). Title of the article in sentence case.
    Journal Name in Title Case, 12(3), 45-67. doi:10.xxxx/xxxxxx
```

## 其他

- **IEEE**（工科）：文内方括号数字 `[1]`，文末按引用顺序编号。
- **MLA**（人文）：文内 `(作者 页码)`，文末 Works Cited。

按你学科 / 期刊的要求选定一种，`build_academic_docx.py` 会把参考文献段落套成悬挂缩进。
