# 学术书面报告

**定位**：帮你把手里的事实、数据、读过的文献，组织成结构规范、逻辑清晰、引用得体的
报告初稿。分工是——你提供内容（论据/数据/文献），我负责框架、逻辑主线、格式与自查。
产出是**给你继续填充和打磨的骨架**，不是可直接冒名提交的成品。应独立完成的作业请自己写，
这里只帮你搭结构、理逻辑、规范格式。

## 第一步：定类型，选骨架

先问清三件事，别急着写：
1. **哪种报告**？文献综述 / 课程论文（研究报告）/ 实验报告
2. **给谁看、什么要求**？字数、引用格式（GB/T 7714？APA？）、有无模板
3. **你手上有什么**？已读文献、已有数据、还是只有题目（只有题目就先帮你缩小范围、列提纲）

## 三种骨架

### 文献综述

综述的命门是**综合，不是罗列**——读者要的是"这个领域的地图"，不是"我读过的论文列表"。

```
一、引言：界定主题范围 + 为什么重要 + 本综述的组织线索（按什么维度展开）
二、主体：按【主题/方法/时间/流派】择一分组，每组内比较不同研究的异同与争论
        —— 每段一个观点，用多篇文献支撑一个论断，而不是一段讲一篇
三、批判性综合：目前的共识是什么、分歧在哪、还有哪些空白（这段最见功力）
四、结论与展望：小结 + 未解问题 + 未来方向
参考文献
```

### 课程论文 / 研究报告（IMRaD 变体）

```
标题 · 摘要（200 字内：背景一句、做了什么、发现什么、意味着什么）
一、引言：漏斗式——大背景 → 已有研究的缺口 → 本文要解决的问题
二、方法/材料：写到别人能复现的程度
三、结果：只客观陈述发现，配图表；不在这里解释
四、讨论：回扣引言的缺口，讲清"这说明了什么" + 局限性
五、结论：不引入新信息，收束全文
参考文献
```

### 实验报告

```
实验目的 · 实验原理 · 材料与方法 · 结果（数据/图表）· 分析与讨论 · 结论 · 参考文献
```

## 一条逻辑主线贯穿全文

好报告像一条线，不是几个段落的拼盘。用这条弧串起来：

**钩子（为什么这问题重要）→ 背景/机制（前人做到哪）→ 证据（数据/文献支撑）→ 应用/结论（所以呢）**

自查：把每一节的第一句连起来读，能不能顺成一个完整的故事？读不通就是逻辑断了。

## 分节写作要点

- **引言**：漏斗结构，从宽到窄，最后一句必须落到"本文做什么"。
- **方法**：过去时、被动或第一人称按学科惯例；写到可复现。
- **结果**：只陈述，不解释。留到讨论再评价。
- **讨论**：先回答引言提的问题，再讲 so what，最后诚实写局限——写局限不减分，反而显专业。
- **结论**：不放新数据、新引用，只收束。

## 报告里的图表（如果要配）

- 图表标题直接写**结论**（"A 组显著高于 B 组"），不写"两组对比图"这种变量名。
- **一图一个观点**，不堆砌；图注交代数据口径、样本量、误差含义。
- 正文里必须有一句话把图"讲"出来并引用（如"如图 1，……"），不能甩张图不管。

## 引用规范（重点）

**文内引用 + 文末参考文献表配套出现**，两种主流格式：

- **GB/T 7714-2015（中文学术国标）**
  - 文内：顺序编码 `……已有研究[1]` 或著者-出版年 `（张三，2023）`
  - 文末：`[1] 张三. 论文标题[J]. 期刊名, 2023, 12(3): 45-67.`（期刊 [J]/专著 [M]/学位论文 [D]/网络 [EB/OL]）
- **APA 7th（国际通用）**
  - 文内：`(Zhang, 2023)` 或 `Zhang (2023) argued...`
  - 文末：`Zhang, S. (2023). Title of the article. Journal Name, 12(3), 45–67. doi:10.xxxx/xxxxxx`（DOI 用 doi: 前缀写法）

IEEE（工科，方括号数字）、MLA（人文）按学科要求切换。**全文只用一种，别混。**

## 学术诚信红线（务必守住）

- **不编造文献**：我不能凭空生成真实的作者/年份/DOI——那是幻觉，查重和导师一眼识破。
  凡是具体引用，我给的都是**格式示例**，你必须用真实读过的文献替换、逐条核实（撤稿的别引）。
- **按证据说话**：论断的强弱要匹配证据强度，别把"一项小样本研究"写成"已证实"。
- **AI 使用要披露**：用 AI 辅助写作，按你学校/期刊的规定如实说明。
- **应独立完成的作业自己写**：本 skill 帮结构、逻辑、格式，不替你把该原创的内容做完。
- **用自己的话表达**：直接复制会触发查重/AIGC 检测；理解后重述才是你的。

## 导出为 Word 文档（若运行环境支持）

学术作业通常要交 `.docx`。若你的 AI 助手能生成文件（有 pandoc 或 python-docx 等），
把成稿直接导出为规范 Word：

- 正文**宋体小四、1.5 倍行距**；标题**黑体**分级；西文用 Times New Roman
- 表格用三线表或标准网格；图**居中**并带"图 1 …"编号图注
- 参考文献按选定格式、悬挂缩进
- 最简路径：先出 Markdown 成稿，再 `pandoc report.md -o report.docx`；
  或用 python-docx 设好中文字体后保存

若运行环境不能生成文件，就输出**规范 Markdown**，并提示用户自行用 Word 或 pandoc 转换。
无论哪种，先把内容和结构写对，Word 只是最后一步的形态。

## 交付格式

```
【类型判定】综述 / 课程论文 / 实验报告 —— 及理由
【完整骨架】逐节列出：每节写什么 + 该节的要点/该问的问题 + 建议字数
【引用模板】按选定格式给文内 + 文末各一条示例（提醒：需替换为真实文献）
【自查清单】逻辑主线是否连贯 / 结果与讨论是否分离 / 引用格式是否统一 /
            是否有未核实的引用 / 是否需要披露 AI 使用
```

先交骨架和清单，让用户填充；用户回填内容后，再逐节帮他打磨措辞与逻辑。
