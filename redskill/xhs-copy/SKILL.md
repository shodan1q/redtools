# 小红书文案

产出可直接粘贴进小红书发布框的文字。默认交付：**3 个标题方案 + 1 篇正文 + 标签组 + 互动引导**。
用户只要其中一样时按需给。

## 标题（决定 70% 的点击）

≤20 字，从这些公式里选 2–3 种各出一个方案，并说明各自的适用场景：

| 公式 | 例 |
|---|---|
| 数字盘点 | 普通人用 AI 的 5 个段位，你在哪层 |
| 反常识 | AI 不会取代人类？这话可能是自我安慰 |
| 结果前置 | 坚持晨跑 100 天，我退掉了健身房 |
| 身份代入 | 给程序员的 3 条转型建议 |
| 悬念缺口 | 为什么你存不下钱？答案在这张图里 |
| 强共鸣 | 原来不是我懒，是方法一开始就错了 |

避免：浅谈/浅析、纯名词堆砌、无数字无冲突、超 20 字。

## 正文 caption（≤1000 字）

```
开头 1–2 句钩子（别复读标题，给新信息或情绪）

✅ 核心点一（emoji 开头，一行一点，3–5 行）
✅ 核心点二
📌 最有用的一条放最后压轴

一句互动引导（具体的问题 > "你觉得呢"）
```

- 说人话：短句、口语、有"你"；具体数字 > 模糊形容。
- emoji 每行最多 1–2 个，选常见的（✅🔥📌💡❗️👉），别整段堆。
- 每篇给读者一个"带得走"的东西：数据、清单、金句，三选一。

## 标签（5–10 个，三层结构）

```
2–3 个大流量词（#AI #职场 #学习方法）
+ 3–5 个垂直词（#AI工具推荐 #时间管理技巧）
+ 1–2 个长尾/场景词（#打工人自救指南）
```

标签要和正文真实相关——堆无关热词会被判营销号降权。

## 合规红线（踩了就限流）

- 绝对化：最、第一、绝对、100%有效
- 医疗/功效断言：治好、根治、瘦十斤保证
- 导流暗示：留站外联系方式、把链接往评论区放
- 贬损竞品、虚构身份（"我是三甲医生"类人设需真实）
