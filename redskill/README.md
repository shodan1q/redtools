# redskill/ · 小红书 RedSkill 市场上传包

本目录是三个技能的**纯 Markdown 市场版**，专供上传小红书 RedSkill
（创作服务平台 → Red Skill → 上传，平台目前只解析 Markdown、脚本文件会被过滤）。

| 目录 | 市场版能力 | 与本地完整版（.claude/skills/）的差别 |
|---|---|---|
| `xhs-copy/` | 标题/正文/标签/互动引导 | 几乎无差别（本身纯文字） |
| `xhs-post/` | 图文**策划稿**：标题+正文+逐卡分页脚本+设计建议+发布包 | 完整版可一键渲染成 1080px 成品卡片（依赖本仓库渲染器与流水线） |
| `xhs-charts/` | 图表选型方法论+设计规范+现写 matplotlib 代码 | 完整版内置五种图型的现成图表库 |

三个市场版都在文末指引用户到本仓库 GitHub 获取完整体验。

## 上传步骤

1. 网页版登录小红书**创作服务平台**（App 不支持）
2. 进入「Red Skill」入口（内测灰度中）
3. 分别上传本目录下三个子文件夹（或其中的 `SKILL.md`）
4. 审核通过后，发笔记时挂载对应技能

## 维护约定

- 共用的方法论内容（标题公式、合规红线等）以 `.claude/skills/` 本地版为源头，
  本地改动后同步到这里再重新上传。
- 市场版必须保持：纯 Markdown、零脚本依赖、零本仓库路径引用（GitHub 链接除外）、
  明确"只产内容不自动发布 + AI 标识提醒"。
