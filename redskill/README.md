# redskill/ · 小红书 RedSkill 市场上传包

本目录是若干技能的**纯 Markdown 市场版**，专供上传小红书 RedSkill
（创作服务平台 → Red Skill → 上传，平台目前只解析 Markdown/TXT，脚本文件会被过滤）。

## 上传就绪状态（全部通过校验）

| 技能 | 状态 | 市场版能力 |
|---|---|---|
| `xhs-copy/` | ✅ 可上传 | 标题/正文/标签/互动引导（纯文字） |
| `xhs-post/` | ✅ 可上传 | 图文策划稿：标题+正文+逐卡分页+设计建议+发布包 |
| `xhs-charts/` | ✅ 可上传 | 图表选型方法论+设计规范+现写 matplotlib 代码 |
| `academic-report/` | ✅ 可上传 | 学术书面报告：综述/课程论文/实验报告框架 + 引用规范 + 诚信自查（通用工具，非 xhs 内容） |
| `product-design-doc/` | ✅ 可上传 | 硬件/智能硬件产品设计方案书：章节骨架 + 工程写作规范 + 安全合规红线框 + Word 导出（通用工具） |

随时可自检（新增技能后务必跑一遍）：

```bash
python3 pipeline/validate_redskill.py
```

校验器把 RedSkill 的硬规则固化成检查：纯 Markdown、frontmatter 合规、name 合法
（小写+连字符、禁下划线/保留词）、**正文无外链导流**、无敏感词。全绿才提交。

## 上传步骤

1. 网页版登录小红书**创作服务平台**（App 不支持）→ 进入「Red Skill」入口（内测灰度中）
2. 逐个上传 `xhs-copy/` `xhs-post/` `xhs-charts/` 三个子文件夹（各含一个 SKILL.md）
3. 填写提交表单：
   - **名称/描述**：取自各 SKILL.md 的 frontmatter
   - **来源**：填 GitHub 仓库地址 `github.com/shodan1q/redtools`
     —— 外链只填这里，**不要写进技能正文或笔记正文**（站内导流会被拒审/处罚）
   - **场景标签**：如「内容创作」「文案」「数据可视化」
4. 审核通常几分钟生效，通过后发笔记时挂载对应技能

## 为什么正文里没有 GitHub 链接

小红书对站内正文外链导流"严厉打击"，但上传表单专门有「来源」字段收 GitHub 地址。
所以三个市场版正文都不含任何 `http(s)://` 链接与仓库路径——完整版一律通过「来源」
字段指向，既合规又不影响用户找到开源仓库。挂载笔记（`挂载笔记文案.md`）同理，
正文用"GitHub 搜 shodan1q/redtools"这类非链接表述。

## 维护约定

- 共用方法论（标题公式、合规红线等）以 `.claude/skills/` 本地版为源头，
  本地改动后同步到这里，再跑 `validate_redskill.py`，全绿再重新上传。
- 市场版必须保持：纯 Markdown、零脚本依赖、**正文零外链**、明确"只产内容不自动
  发布 + AI 标识提醒"。
- 每个技能包 = 一个目录 + 一个 SKILL.md；`README.md` 与 `挂载笔记文案.md` 是本目录
  的说明文件，不作为技能上传。
