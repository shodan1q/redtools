# redskill/ · 小红书 RedSkill 市场上传包

本目录是各技能的**上传版**（与 `.claude/skills/` 本地版同源），供上传小红书 RedSkill。

> **上传规则（2026-07，以创作平台上传页为准）**：上传含 `SKILL.md` 的文件夹，
> **支持 .md/.txt/.html/.css/.js/.py/.json/.xml 等代码与配置文件**（脚本可带，不再被过滤）；
> 单文件 ≤10MB、技能包总大小 ≤30MB；内容来源分「原创/转载」，需同意《Skill 发布安全规范》。

## 上传就绪状态（全部通过校验）

| 技能 | 状态 | 能力 | 形态 |
|---|---|---|---|
| `xhs-copy/` | ✅ | 标题/正文/标签/互动引导 | 纯 MD |
| `xhs-post/` | ✅ | 图文策划稿：标题+分页+设计建议+发布包 | 纯 MD |
| `xhs-charts/` | ✅ | 图表选型+设计规范+现写 matplotlib 代码 | 纯 MD |
| `academic-report/` | ✅ | 发表级学术报告：综述/论文/实验报告 + **一键出 Word 脚本** + 学术插图脚本 | MD + scripts |
| `product-design-doc/` | ✅ | 硬件产品方案书：章节骨架+工程写作规范+安全红线框 | 纯 MD |

随时可自检（新增/改动技能后务必跑一遍）：

```bash
python3 pipeline/validate_redskill.py
```

校验器固化了 RedSkill 硬规则：文件类型合法、单文件≤10MB/总≤30MB、frontmatter 合规、
name 合法（小写+连字符、禁下划线/保留词）、正文外链与敏感词提示。全绿才提交。

## 上传步骤

1. 网页版登录小红书**创作服务平台**（App 不支持）→ 进入「Red Skill」入口
2. 选择「上传文件 → 选择文件夹」，逐个上传各技能子文件夹（含 SKILL.md，可含 scripts/）
3. **内容来源**选「原创」；勾选同意《Skill 发布安全规范》
4. 填提交表单：
   - **名称/描述**：取自各 SKILL.md 的 frontmatter
   - **来源**：GitHub 仓库地址 `github.com/shodan1q/redtools`
     —— 外链填这里，**不要写进技能正文或笔记正文**（站内导流会被判罚）
   - **场景标签**：如「内容创作」「文案」「数据可视化」「学习/论文」
5. 审核通常几分钟生效，通过后发笔记时挂载对应技能

## 为什么正文里不放 GitHub 链接

小红书对站内正文外链导流“严厉打击”，但上传表单专门有「来源」字段收 GitHub 地址。
所以各技能正文都不含 `http(s)://` 链接——通过「来源」字段指向仓库，既合规又不影响
用户找到开源仓库。挂载笔记（`挂载笔记文案.md`）同理，正文用“GitHub 搜 shodan1q/redtools”这类非链接表述。

## 维护约定

- 共用方法论以 `.claude/skills/` 本地版为源头，改动后同步到这里，跑
  `validate_redskill.py` 全绿再上传。
- 技能包可带 scripts/ 脚本与 references/，但注意 10MB/30MB 限制、别把 `__pycache__`
  等打包进去；**正文仍不放外链**；坚持“只产内容不自动发布 + AI 标识提醒”。
- `README.md` 与 `挂载笔记文案.md` 是本目录的说明文件，不作为技能上传。
