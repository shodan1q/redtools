# 挂载笔记文案（上传 skills 时发布的笔记，正文 ≤1000 字）

**发布标题**：我把「做小红书图文」写成了 3 个 AI 技能，点一下就能装

**正文**：

以前做一篇图文笔记：想标题 1 小时，写文案 1 小时，排版做图 2 小时。现在我把整套流程写成了 3 个可安装的 AI 技能，就挂在这篇笔记下面，点一下装进你的 AI 助手。

✅ xhs-copy 文案专家：给一个主题，返回 3 个标题方案（标注公式和推荐理由）+ 正文 + 三层标签组 + 互动引导，直接粘进发布框
✅ xhs-post 图文一条龙：从想法到整篇笔记的策划稿——正文、逐张卡片的分页脚本（每张卡写什么）、按内容类型给的配色字体建议、发布包一次出齐
✅ xhs-charts 数据图表：按"你想说哪句话"选图型（占比/趋势/对比/点阵），配色字号全按手机端阅读优化，能直接写出做图代码

三个技能守同一条底线：只帮你生产内容，发布永远由你自己完成，不碰任何自动发布——那是平台红线。AI 参与的内容，发布时记得勾选"AI 生成"标识。

想要完整体验（一键渲染 1080×1440 成品卡片、16 套配色主题、5 种数据图表的完整流水线），这三个技能是开源项目 redtools 的市场版，完整版在 GitHub 搜 shodan1q/redtools，下载后在 Claude Code 里说一句"帮我做一篇××的小红书"，从文案到成品图一条龙。
