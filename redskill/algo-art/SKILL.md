# 生成式算法艺术

不是画具体图案，而是让美感从**算法过程**里涌现：给一个种子，程序跑出一张谁都没见过的图。
换种子就换作品——所以每张都独一无二，天然适合当封面 / 壁纸 / 背景。

方法论借鉴 Anthropic 的 `algorithmic-art` 技能（Apache-2.0），此处改写为**中文、自包含、直接出
PNG**（用 Python 的 numpy + Pillow，不需要浏览器）。

## 四种风格（`scripts/art.py`）

| 关键字 | 风格 | 长什么样 |
|---|---|---|
| `flow` | 有机湍流·流场 | 上千粒子沿噪声力场流动，黑底上织出发光丝线纹理 |
| `wave` | 量子谐波·波干涉 | 多波源叠加干涉，呼吸般的斑纹场（像熔岩 / 珊瑚） |
| `cells` | 随机结晶·Voronoi | 随机点长成细胞镶嵌，像彩色玻璃 / 宝石拼片 |
| `tree` | 递归低语·分形树 | L 系统式递归枝桠，像冬日树影 / 蒲公英剪影 |

## 怎么用

```bash
# 出一张流场（默认深海霓虹配色、随机种子）
python3 scripts/art.py flow

# 指定风格 + 配色 + 种子 + 输出
python3 scripts/art.py tree --palette 莫兰迪雾 --seed 5 --out cover.png

# 四种各出一张
python3 scripts/art.py all
```

- **配色**（`--palette`）：`深海霓虹` / `赛博落日` / `松石森林` / `莫兰迪雾`
- **换种子出新图**（`--seed`）：不满意就换个数字重跑，几秒一张，挑到喜欢的为止
- **尺寸**（`--size`，默认 1400）：要竖版封面可自行改脚本裁剪
- 没有 Python 环境时，本技能也能作为"生成艺术提示词"指导 AI 写 p5.js 版本

## 出图小技巧

- 想要**高级感留白**：`tree` 或 `flow`，深底 + 少量亮色，标题压上去很稳
- 想要**满屏视觉冲击**：`wave` 配 `赛博落日`，或 `cells` 配 `松石森林`
- 同一风格连出 6–9 张不同种子，拼成一组，是小红书很吃的"AI 生成艺术"选题

## 原则

- **过程即美**：每次运行都不同，别把它当固定模板
- **原创，不抄袭**：算法生成的是全新图案，不复制任何现有画师的作品
- 依赖：`numpy`、`Pillow`（大多数带 Python 的环境都有，没有就 `pip install numpy pillow`）
