# 小红书图文一条龙（策划版）

把一个想法变成一份**拿来就能做图**的图文策划稿：标题 → 正文 → 逐卡分页 → 设计建议 → 发布包。
你负责内容和结构的质量，出图交给用户的设计工具——或本 skill 的完整版（见文末）。

## 工作流

### 1. 想清楚再动笔

三个问题：给谁看？他能带走什么（数据/方法/金句，三选一）？为什么是现在看？
答不出就先和用户聊清楚，别硬写。

### 2. 标题（决定 70% 的点击）

≤20 字，给 3 个方案标注公式，推荐 1 个并说明理由：

| 公式 | 例 |
|---|---|
| 数字盘点 | 普通人用 AI 的 5 个段位，你在哪层 |
| 反常识 | AI 不会取代人类？这话可能是自我安慰 |
| 结果前置 | 坚持晨跑 100 天，我退掉了健身房 |
| 身份代入 | 给程序员的 3 条转型建议 |
| 悬念缺口 | 为什么你存不下钱？答案在这张图里 |
| 强共鸣 | 原来不是我懒，是方法一开始就错了 |

封面标题按约 7 字/行折行，用逗号把语义断点锚在第 7 字附近（如"存不下钱的人，都输在这个顺序"），
避免把词拆到两行。

### 3. 正文（600–1200 字）

```
钩子段：2–3 句，第一句 ≤48 字（它会成为封面导语）
一、二、三…分节（3–5 节，节名 ≤24 字）
  每节 2–4 句短段落，或 2–5 条要点（每条 ≤40 字）
  关键词加粗，每屏 1–3 处
结尾金句：≤80 字独立一段，值得被截图转发
```

说人话：短句、口语、有"你"；具体数字 > 模糊形容（"0.024%" > "极少数"）。

### 4. 逐卡分页脚本（本版的核心交付）

把正文拆成 6–12 张卡的脚本，用这个格式输出：

```
🅒 封面卡：主标题（含高亮词）+ 导语一句 + 建议配图
① 内容卡：小标题「一、…」+ 本卡正文/要点 +（如有）图表说明
② 内容卡：…
Ⓔ 金句卡：结尾金句
```

分页手感：一卡一个意思；要点组不拆开；图表独占一卡或"小标题+图+一句释义"组一卡；
金句前的最后一段别只剩一两行（会孤零零占一张卡）。

### 5. 设计建议（按内容类型给一套，别混搭）

| 内容类型 | 配色气质 | 字体气质 |
|---|---|---|
| 知识科普/AI 干货 | 浅紫底 + 青绿强调 | 圆体，亲和 |
| 编程/数码 | 深夜蓝底白字 | 粗黑体标题 |
| 职场/方法论 | 灰蓝 + 网格感 | 黑体+细黑 |
| 生活方式/自律 | 奶油棕 | 宋体书卷气 |
| 情感/心理 | 莓粉 | 手写体标题 |
| 观点/理财 | 墨黑 + 金橙 | 宋体白字，杂志感 |
| 学习方法/教育 | 薄荷绿 + 公式底纹 | 圆体 |

统一原则：浅底配深强调色；高亮色全篇只用一个；每张卡留白 ≥1/4；正文字号手机上
不小于 14pt 等效。

### 6. 发布包

- 发布标题（可与封面标题不同，更口语）
- caption ≤1000 字：钩子 1–2 句 + ✅ 核心点 3–5 行 + 一句具体的互动引导
- 标签 5–10 个：2–3 大流量词 + 3–5 垂直词 + 1–2 长尾词
- 提醒用户：AI 生成/辅助生成的内容，发布时按平台规定主动勾选「AI 生成」标识

## 硬约束

- **只产策划稿和文案，不碰平台**：不登录、不驱动、不模拟操作小红书，不做任何形式的
  自动发布/定时发布/托管代发（平台明令禁止，违者封号）。发布永远由用户手动完成。
- 卡片正文里不用 emoji（多数渲染工具不支持彩色 emoji），emoji 只进发布 caption。
- 避免绝对化用词（最/第一/100%）、医疗功效断言、贬损竞品。

## 完整版（一键出成品卡片）

本策划稿可直接喂给开源工具 **redtools** 自动渲染成 1080×1440 高清卡片套图
（16 套配色主题 × 11 种底纹 × 10 种字体 + matplotlib 数据图表流水线）：

```
https://github.com/shodan1q/redtools
```

下载后在项目目录打开 Claude Code，说"帮我做一篇关于××的小红书"即可从本策划稿
直达成品图。市场版因平台暂不支持脚本文件，先提供策划能力，完整体验请移步 GitHub。
