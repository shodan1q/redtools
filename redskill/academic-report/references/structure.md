# 三种报告的结构骨架

选类型 → 照骨架搭 → 每节按要点写。骨架里的「§」是建议章节，可按要求增删。

## 文献综述

命门是**综合，不是罗列**——读者要"这个领域的地图"，不是"我读过的论文清单"。

```
摘要（150–250 字）
§1 引言：界定主题范围 + 为什么重要 + 本综述的组织线索（按什么维度展开）
§2 主体：按【主题 / 方法 / 时间 / 流派】择一分组
        每段一个观点，用多篇文献支撑一个论断（≠ 一段讲一篇）
§3 批判性综合：共识是什么、分歧在哪、空白在哪（最见功力）
§4 结论与展望：小结 + 未解问题 + 未来方向
参考文献
```

## 课程论文 / 研究报告（IMRaD）

```
标题 · 摘要（背景一句、做了什么、发现什么、意味着什么）· 关键词 3–5 个
§1 引言：漏斗式——大背景 → 已有研究的缺口 → 本文要解决的问题
§2 方法 / 材料：写到别人能复现的程度
§3 结果：只客观陈述发现，配图表；不在这里解释
§4 讨论：回扣引言的缺口，讲清"这说明了什么" + 局限性
§5 结论：不引入新信息，收束全文
参考文献 · （附录）
```

## 实验报告

```
§1 实验目的
§2 实验原理（公式、定律；公认原理无需大量引用）
§3 材料与方法
§4 结果（数据表 + 图 + 必要的定量分析，如线性拟合 / 误差）
§5 分析与讨论（吻合程度、误差来源、局限）
§6 结论
参考文献
```

## 学位论文（博士 / 硕士，GB/T 7713.1-2006）

完整学位论文比单篇报告多"前置 + 后置"部分，章节用三级编号（1 / 1.1 / 1.1.1）。

```
【前置部分】
  封面 / 题名页：正题名须中英文对照
  中文摘要（300–600 字）+ 关键词 3–8 个
  英文摘要（Abstract，实词约 300）+ Keywords（与中文对应）
  目录（页码从"绪论"起用阿拉伯数字连续编码）
  （可选）图目录 / 表目录 / 主要符号与缩略语表
【主体部分】
  1 绪论：研究背景与意义 → 国内外研究现状（这就是文献综述）→ 存在问题
          → 本文研究内容与技术路线 → 论文组织结构
  2 …  相关理论 / 方法 / 关键技术
  3 …  设计 / 建模 / 实验
  4 …  结果与分析
  5 结论与展望：结论（对应各章）+ 创新点 + 不足与展望
  参考文献（GB/T 7714）
【后置部分】
  附录 / 致谢 / 攻读学位期间取得的成果
```

- **绪论 vs 结论**：绪论提出问题与路线；结论回收每一章的发现 + 明确列创新点。
- **每章自成体系**：章首一段导语（本章做什么），章末一段小结（本章得到什么）。
- 用 A4 纸；`build_academic_docx.py` 已按 GB 设 A4 + 左侧装订边距。

## 贯穿全文的一条逻辑主线

好报告像一条线，不是段落拼盘。用这条弧串起来：

**钩子（为什么重要）→ 背景 / 机制（前人到哪）→ 证据（数据 / 文献）→ 应用 / 结论（所以呢）**

自查：把每节第一句连起来读，能顺成一个完整故事吗？读不通就是逻辑断了。

## 分节写作要点

- **引言**：漏斗结构，从宽到窄，最后一句落到"本文做什么"。
- **方法**：写到可复现；按学科惯例用过去时 / 被动。
- **结果**：只陈述，不解释；解释留到讨论。
- **讨论**：先回答引言的问题 → 讲 so what → 诚实写局限（写局限不减分，反显专业）。
- **结论**：不放新数据、新引用，只收束。
- **防孤儿页 / 空节**：每节至少 2–3 句实质内容，别留空壳标题。

## 图表（交给 make_figure.py）

- 图/表标题写**结论**（"六周后差距拉开"），不写变量名（"成绩变化图"）。
- 一图一个观点；图注交代口径、样本量、误差含义。
- 正文必须有一句话引用并解读（"如图 1，……"），不能甩图不管。
- 图题注写在图**下方**（`图1 …`），表题注写在表**上方**（`表1 …`）——中文规范。
